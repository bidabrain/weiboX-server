对外 API

第三方客户端用 Bearer Token 调用。Token 见服务器 data/api_token.txt。

  • GET /api/v1/timeline?limit=50&offset=0 — 聚合时间线
  • GET /api/v1/users — 关注列表
  • GET /api/v1/users/{uid}/posts — 某用户微博
  • GET /api/v1/status — 抓取状态
